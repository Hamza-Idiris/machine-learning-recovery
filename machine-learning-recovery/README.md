# Machine Learning Recovery

A practical, lesson-by-lesson Machine Learning learning repository using Python, pandas, NumPy, and scikit-learn.

## How we work
1. Study one lesson at a time.
2. Run the notebook cells.
3. Complete the exercises independently.
4. Review the work before moving to the next lesson.
5. Build practical projects and complete the final assessment.

## Setup

```bash
python -m venv .venv
```

Windows PowerShell:
```powershell
.venv\Scripts\Activate.ps1
```

Install and launch:
```bash
pip install -r requirements.txt
jupyter lab
```

## Structure
- `lessons/` — lesson notebooks, notes, and exercises
- `datasets/` — learning datasets or download instructions
- `projects/` — mini-projects and final project
- `progress.md` — completion tracking
- `certificates/` — completion certificate, once earned

This is a self-directed learning repository. Any completion certificate will be a personal course-completion certificate, not an accredited qualification.
